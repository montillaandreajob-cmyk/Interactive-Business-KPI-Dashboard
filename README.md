# Business KPI Dashboard | HTML + CSS + JavaScript

A responsive, interactive **fictional** dashboard for practicing front-end development and business KPI storytelling. Users can filter sales opportunities by channel and view conversion, pipeline value, and opportunity stages. A lightweight chart uses HTML/CSS only.

## Context
Independent web development and analytics portfolio project, informed by my background in programming studies and business operations. **This is not a website or source code that I built for an employer or submitted as a university assignment.** All records are made up.

## Run
Open `index.html` in a browser. No installation or internet connection required.

## How to use
- Choose a channel using the dropdown.
- The four KPI cards, stage bars, and example record table update instantly.
- The reset button returns to all channels.

## Technologies
HTML5, CSS3, vanilla JavaScript (ES2020), responsive grid layouts, accessible labels, DOM updates and array aggregation.
